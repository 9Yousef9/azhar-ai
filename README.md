# Azhar AI Study Assistant — أزهر AI

مساعد دراسي عربي لطلاب الأزهر. الخادم بلا اعتماديات (Node.js 18 أو أحدث) ولا يتطلب أي اشتراك.

## التشغيل
```
cp .env.example .env      # ثم ضع مفتاحك في GEMINI_API_KEY (اختياري)
node server.js            # افتح http://localhost:3000
node test.js              # اختبار ذاتي (خادم Gemini وهمي، بلا مفتاح حقيقي)
```
أو بدون ملف: `GEMINI_API_KEY=مفتاحك node server.js`

## المفتاح والتكلفة
- المفتاح يُقرأ من المتغير `GEMINI_API_KEY` على الخادم فقط، ولا يوجد في `public/` ولا يُرسل للمتصفح. لا ترفع ملف `.env` إلى GitHub.
- تستطيع إنشاء مفتاح من Google AI Studio. الحصة المجانية وحدودها وشروطها تحددها Google وتتغير، فراجعها هناك. هذا المشروع لا يشتري شيئًا ولا يفترض وجود حصة.
- بدون مفتاح: تظهر رسالة واضحة في أقسام الذكاء الاصطناعي، وبقية الموقع (المواد، الدروس، المؤقت، المهام، التقدم) يعمل طبيعيًا.
- حماية التكلفة: `PER_MIN_LIMIT` (افتراضي 15 طلب/دقيقة لكل جهاز) و`DAILY_LIMIT` (افتراضي 300 طلب/يوم للموقع كله). النموذج عبر `GEMINI_MODEL`.
- خلف وكيل عكسي (Render وغيره) ضع `TRUST_PROXY=1`.

## حفظ التقدم
يُحفظ تقدم الطالب في `localStorage` بالمتصفح ويُستعاد عند فتح الموقع. الحسابات والمزامنة بين الأجهزة غير مضمّنة بعد.

## الهيكل
`server.js` الخادم وبوابة Gemini · `public/index.html` الواجهة · `test.js` الاختبار
